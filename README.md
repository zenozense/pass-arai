## 🧩 รายละเอียดโปรเจ็ค

**Pass-arai** เป็นโปรแกรมภาษา Python ที่สามารถ
- สร้างรหัสผ่านที่ปลอดภัย (สุ่มตัวอักษร ตัวเลข คำศัพท์ และสัญลักษณ์พิเศษ)
- มีระบบ **ล็อกอิน / สมัครสมาชิก** เพื่อยืนยันตัวตน
- มีระบบบันทึกรหัสผ่านที่สร้างไว้ได้พร้อมหมายเหตุ
- เชื่อมต่อกับฐานข้อมูล (MongoDB)
- ออกแบบให้ใช้งานง่ายและปลอดภัย
- สามารถบันทึกออกเป็น .txt ได้อย่างรวดเร็ว
- สามารถตรวจสอบความแข็งแรงของรหัสผ่านได้ (Entropy bits)
- สามารถวิเคราห์รหัสผ่าน Custom ได้
- มีระบบแนะนำการตั้งรหัสผ่านเพื่อให้ได้ความปลอดภัยที่สูงขึ้น

## ⚙️ ฟังก์ชันหลัก

### ✅ ระบบล็อกอิน (Authentication)
- สมัครสมาชิกใหม่ (Register) และเข้าสู่ระบบ (Login)
- เก็บรหัสผ่านแบบเข้ารหัส (Hash) ด้วย `bcrypt`

### ✅ ระบบสร้างรหัสผ่าน (Password Generator)
- ตั้งค่าความยาวของรหัสผ่าน
- เลือกว่าจะใช้ ตัวพิมพ์ใหญ่ / ตัวพิมพ์เล็ก / ตัวเลข / สัญลักษณ์ / คำศัพท์
- คัดลอกรหัสผ่านได้ทันที
- Export ข้อมูลเป็น .txt ได้อย่างรวดเร็ว

### ✅ ระบบบันทึกรหัสผ่าน (History)
- บันทึกข้อมูลการสร้างรหัสผ่าน เช่น  
  - รหัสผ่านที่บันทึกไว้
  - หมายเหตุ
  - วันที่และเวลาที่สร้าง  
- ข้อมูลทั้งหมดถูกเก็บในฐานข้อมูล
- สามารถจัดการ History ได้ (CRUD History Management)

### ✅ ระบบวิเคราห์ความปลอดภัยรหัสผ่าน (Password Analysis)
- มีระบบคำแนะนำการตั้งรหัสผ่านเพื่อความปลอดภัยที่มากขึ้น
- ตรวจสอบรหัสผ่านที่สร้างได้ทันที
- สามารถตรวจสอบความปลอดภัยรหัสผ่านแบบ Custom เองได้
